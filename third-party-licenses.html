第三方开源许可

本站 490 个工具大部分在你自己的浏览器里运行，用到了下列开源组件与模型。感谢这些项目的作者。

文档与压缩包处理

pdf-libMIT

用于 PDF 合并、拆分、旋转、页码、水印等页面。

PDF.js (pdfjs-dist)Apache-2.0

用于 PDF 渲染预览与 PDF 转图片。

JSZipMIT / GPLv3 双许可

用于批量结果的 ZIP 打包下载。

SheetJSApache-2.0

用于 Excel / CSV 的读写与格式转换。

图片与视频

FFmpeg（ffmpeg.wasm）LGPL-3.0

用于视频转码、压缩、裁剪、抽帧、GIF 转换等音视频工具。

libheif / heic-decodeLGPL-3.0

用于 HEIC / HEIF 图片解码。

sharp / libvips（构建期）Apache-2.0 / LGPL-3.0

部分图片处理管线使用的底层图像库。

gif.js / gifencMIT

用于 GIF 动图的编码与生成。

AI 与模型

Depth Anything V2 SmallApache-2.0

用于 3D 照片、深度图生成等工具的单目深度估计模型。

ONNX Runtime WebMIT

模型在浏览器内的推理运行时。

u2net / rembg 权重Apache-2.0

用于图片去背景（抠图）。

Real-ESRGANBSD-3-Clause

用于图片放大与画质增强。

字体与图标

Inter / Noto Sans SCOFL-1.1

界面与正文的中英文字体。

Lucide IconsISC

站内所有线性图标。

其他

Chart.jsMIT

用于图表与数据可视化工具。

CodeMirrorMIT

用于代码编辑、格式化与高亮。

Tesseract.jsApache-2.0

用于图片文字识别（OCR）。

如果你认为本站对某个组件的使用需要补充署名或调整，欢迎联系我们修正。 所有工具均在浏览器本地运行，你的文件不会上传到服务器。
