二维码生成器常见问题解答

这个二维码生成器真的免费吗？

是的。无需账户、订阅或水印即可创建、定制并下载 PNG 或 SVG 格式的二维码。您制作二维码的数量或扫描次数没有限制。

这些二维码会过期吗？

不。这些是静态二维码：链接或文本存储在二维码本身中，只要目标存在，它就会一直有效。许多“免费”生成器制作的是动态二维码，这些二维码指向它们自己的重定向链接，并且在试用期结束后停止工作。在这里生成的二维码完全不依赖 嘉Jaykou工具台。

我的信息上传了吗？

不。验证码是在你的浏览器中生成的。你输入的链接、Wi-Fi 密码或联系人信息以及你添加的任何徽标都会保留在你的设备上。

我可以添加我的标志吗？

是的。添加 PNG、JPG、WebP 或 SVG 徽标，它会被放置在二维码的中间。错误纠正级别提高到高，这样二维码仍然可以被读取。保持徽标简洁，并在打印前用手机测试二维码。

哪些颜色扫描可靠？

在浅色背景上使用深色二维码，并保持强烈对比度。大多数手机相机无法读取深色背景上的浅色二维码。当对比度过低或二维码反色时，生成器会发出警告。

PNG 还是 SVG：我应该下载哪一个？

下载用于打印和设计工具的 SVG：无论大小如何都保持清晰。下载用于网站、幻灯片和消息的 PNG。PNG 大小经过轻微调整，以便每个模块都落在完整的像素上，从而保持边缘清晰。

打印的二维码应该有多大？

作为一条经验法则，代码的尺寸至少应为 2 × 2 厘米（约 0.8 × 0.8 英寸），并且大约是扫描距离的十分之一。保持其周围的边距没有其他图形。

打印后我可以改变代码指向的地方吗？

不可以。静态代码在生成后无法编辑。如果你需要以后更改目标，请将代码指向你控制的页面，然后更新该页面。

What does error correction do?

It adds redundancy so a code can still be read when part of it is dirty, damaged or covered by a logo. Low restores about 7% of the code, Medium 15%, Quartile 25% and High 30%. Higher levels make the code denser.
