我如何查看我的网站在手机上的显示效果？

输入您的网站地址或粘贴您的 HTML，从列表中选择一部手机，并查看页面的精确屏幕尺寸。旋转到横屏或拖动框架到任意宽度。

手机视图有多准确？

该页面以手机屏幕的宽度和高度显示，单位为 CSS 像素，因此媒体查询和布局的响应方式与在该手机上完全相同。

为什么我的网页在真实手机上看起来被缩小了？

它可能缺少 viewport 元标签。没有它，手机会将页面布局为大约 980 像素宽并进行缩放。当粘贴的 HTML 没有这样的标签时，测试工具会提醒你。

为什么网站会保持空白？

有些网站选择不在其他页面中显示。打开“为什么是空白的？”查看网站的头信息，或者直接粘贴页面的 HTML。
