THE CORNER QUESTION

为什么角落击打如此罕见

徽标以稳定的速度斜着移动，并在每条边反弹。它只有在同时到达一侧和顶部或底部时，才会碰到角落。

Think of the free space: the screen width minus the logo width across, and the screen height minus the logo height down. The logo hits a corner when the distance it has travelled is a whole number of widths and a whole number of heights at once.

If the free width and height form a simple ratio, like 3:2, that happens every few bounces. On a typical screen the ratio is far from simple, so the next corner can be many minutes or hours away. Perfect fit picks a logo size that makes the ratio simple; Aim for a corner changes the angle very slightly so the logo lands in a corner soon.

什么是弹跳标志屏保？

经典屏幕保护程序的免费浏览器版本，其中一个标志在屏幕上漂移，撞到边缘时反弹并在每次反弹时改变颜色。你可以使用自己的文字或标志，并且它会统计并庆祝每次碰角。

我如何将它用作屏保？

在您想使用的屏幕上打开此页面，按全屏并保持运行。控制按钮会在几秒钟后消失，在支持的浏览器上，播放徽标时屏幕会保持唤醒状态。

我可以上传我自己的标志吗？

是的。上传 PNG、SVG、JPG 或 WebP。具有透明背景的标志在每次反弹时都会被重新着色。普通背景的标志会移除背景，你也可以通过彩色光晕保留原始颜色。你的图片会保留在你的浏览器中。

它会碰到角落吗？

是的。打开预测可以准确看到下一次撞角何时发生。瞄准角落会稍微调整角度，使球很快落入角落，而完美贴合会让球每隔几次弹跳就撞角。

我可以录制一个视频吗？

是的。打开视频以导出 MP4 或 WebM，比例可为 16:9、9:16 或 1:1，时长从 10 秒到 10 分钟，帧率为 30 或 60 fps，包含弹跳声音，并可选择在结尾添加角落击打效果。

是的。无需注册，无水印，也无需安装任何东西。它可以在手机、平板、笔记本电脑和电视的浏览器中运行。
